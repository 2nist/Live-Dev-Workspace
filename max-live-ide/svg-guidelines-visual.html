🎨 Custom SVG Icon Guidelines

Complete visual guide for creating optimal SVG icons for your Max Live IDE

📐 Grid System & Safe Area

Always design within the 20x20px safe area inside a 24x24px viewBox

Grid Template

Blue dashed area = Safe zone
Grid = 1px squares (scaled up)

Optimal Dimensions

ViewBox: 0 0 24 24 (Fixed)
Safe Area: 2px margin
Icon Content: 20x20px max
Stroke Width: 2px
Corner Radius: 1-2px

📏 Size Scaling & Visual Weight

Your icons should look crisp and balanced at all sizes

🎨 Style Variants

Outline Style (Recommended)

stroke="currentColor"
stroke-width="2"
fill="none"

Filled Style

fill="currentColor"
stroke="none"

Dual-tone Style

fill="currentColor" opacity="0.2"
stroke="currentColor" stroke-width="2"

✅❌ Do's and Don'ts

✅ DO

  • Clean, simple paths
  • Consistent stroke width
  • Rounded line caps
  • Proper viewBox

❌ DON'T

  • Inconsistent stroke weights
  • Unnecessary precision
  • Random colors in SVG
  • Over-complicated paths

🔧 Code Templates

Basic Icon Template

<svg 
  width="24" 
  height="24" 
  viewBox="0 0 24 24" 
  fill="none"
  xmlns="http://www.w3.org/2000/svg"
>
  <path 
    d="Your path data here" 
    stroke="currentColor" 
    strokeWidth="2" 
    strokeLinecap="round" 
    strokeLinejoin="round"
  />
</svg>

React Component Template

export const MyCustomIcon = ({ 
  size = 24, 
  color = 'currentColor', 
  className = '' 
}) => (
  <svg 
    width={size} 
    height={size} 
    viewBox="0 0 24 24" 
    fill="none" 
    className={`devible-icon ${className}`}
    xmlns="http://www.w3.org/2000/svg"
  >
    <path 
      d="..." 
      stroke={color} 
      strokeWidth="2" 
      strokeLinecap="round" 
      strokeLinejoin="round"
    />
  </svg>
);

✅ Quality Checklist

Design Quality

  • Icon fits within 20x20px safe area
  • Uses consistent 2px stroke width
  • Visually balanced and centered
  • Clear and recognizable at 16px
  • Appropriate corner radius (1-2px)

Technical Quality

  • ViewBox is exactly "0 0 24 24"
  • Uses currentColor for flexibility
  • strokeLinecap="round" for smooth ends
  • strokeLinejoin="round" for smooth corners
  • Clean, minimal path data
  • File size under 2KB

Brand Consistency

  • Matches overall visual style
  • Consistent with other icons
  • Works with brand colors
  • Scales well across all sizes
  • Accessible and readable
